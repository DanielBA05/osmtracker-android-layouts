# Parque Central de Grecia

Disposición personalizada de botones para OSMTracker utilizada para el trabajo de campo de Sistemas de Información Geográfica (SIG) en el Parque Central de Grecia, Costa Rica.

## Elementos a mapear

- Banca
- Árbol
- Paso peatonal
- Hidrante
- Parada de taxi
- Monumento
- Parque infantil
- Establecimiento
- Acera
- Basurero

La disposición también incluye botones para registrar fotografías y notas durante el trabajo de campo.

## Archivo

- `es.xml`: disposición de botones en español para OSMTracker.
